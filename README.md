# 🧠 Spring Boot + Spring AI + Ollama Chat API

A simple REST API built with **Spring Boot** and **Spring AI** that integrates with **Ollama** to generate AI-powered chat responses.

---

## 🚀 Features

- ✅ REST endpoint for chat interaction
- ✅ Integration with Ollama LLM
- ✅ Clean Controller–Service architecture
- ✅ Lightweight and easy to extend
- ✅ Ready for streaming & memory upgrades

---

## 🏗️ Tech Stack

- Java 17+
- Spring Boot
- Spring AI
- Ollama
- Maven
